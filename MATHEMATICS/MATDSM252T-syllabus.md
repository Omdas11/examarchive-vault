## Syllabus

| unit_number | syllabus_content | lectures | tags |
|---|---|---|---|
| 1 | Introduction to differential equations, order and degree, Formation of differential equations, Differential equations in which variables are separable, Homogeneous differential equations, First order exact differential equations, Integrating factors, rules to find an integrating factor, Linear differential equations. |  | differential,order,degree,formation |
| 2 | First order higher degree equations solvable for x, y, p, Equations in Clairaut's form. Solving a differential equation by reducing its order, Linear homogenous equations with constant coefficients, linear non-homogenous equations with constant coefficients. |  | first,order,higher,degree |
| 3 | Linear ordinary differential equations with variable coefficients, Cauchy-Euler equation, Equations reducible to homogeneous linear form, Method of variation of parameters. |  | linear,ordinary,differential,variable |
| 4 | Simultaneous differential equations with constant coefficients, Simultaneous differential equations of the form (dx)/P = (dy)/Q = (dz)/R, Total differential equations. |  | simultaneous,differential,constant,coefficients |
| 5 | Order and degree of partial differential equations, concept of linear and non-linear partial differential equations, Formation of first order partial differential equations, Lagrange's method. |  | order,degree,partial,differential |
