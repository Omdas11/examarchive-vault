## Syllabus

| unit_number | syllabus_content | lectures | tags |
|---|---|---|---|
| 1 | Linear Diophantine equation, prime counting function, statement of prime number theorem, Goldbach conjecture, linear congruences, complete set of residues, Chinese Remainder theorem, Fermat's Little theorem. |  | linear,diophantine,prime,counting |
| 2 | Number theoretic functions, sum and number of divisors, totally multiplicative functions, definition and properties of the Dirichlet product, the Mobius Inversion formula. |  | number,theoretic,divisors,totally |
| 3 | Greatest integer function, Euler's function, Euler's theorem, reduced set of residues, some properties of Euler's phi-function. |  | greatest,integer,euler,reduced |
| 4 | Order of an integer modulo n, primitive roots for primes, composite numbers having primitive roots, Euler's criterion, the Legendre symbol and its properties. |  | order,integer,modulo,primitive |
| 5 | Basic combinatorial numbers, basic counting principle, permutation and combinations, the multinomial theorem, properties of binomial coefficients, partitioning of a set, The Pigeonhole Principle, the inclusion & exclusion principle. |  | combinatorial,numbers,counting,principle |
